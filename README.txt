# Sistema de Gestión de Búsqueda de Personas - versión básica

Proyecto Java de consola preparado para IntelliJ IDEA y pensado para una clase introductoria de Programación II.

## Contenido utilizado
- Clases y objetos.
- Atributos `private` y `protected`.
- Constructores.
- Métodos.
- Encapsulamiento con getters y setters.
- Herencia con `extends` (`Caso extends Persona`) y `super`.
- Arreglos para guardar registros.
- `Scanner`, `if`, `switch`, `while` y `for`.

No utiliza Swing, Maven, streams, lambdas, bases de datos ni estructuras avanzadas.

## Cómo ejecutar
1. Descomprime el ZIP.
2. En IntelliJ IDEA abre la carpeta `SistemaBusqueda_Basico_IntelliJ`.
3. Abre `src/Main.java`.
4. Ejecuta el método `main` con el botón verde.
5. Se recomienda JDK 8 o superior.

Esta es una versión básica de consola para practicar los temas iniciales de clase. Los datos permanecen en memoria mientras el programa está abierto; al cerrarlo se pierden. Usa únicamente información ficticia en las pruebas. El sistema es un prototipo académico y no sustituye una denuncia ni una confirmación oficial.
